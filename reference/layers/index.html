ClipRect

struct

Public ClipRect envelope. The library may allocate a larger private record; callers must follow only this published prefix. Public layer ClipRect lists are singly linked through F:Amiga.ClipRect.Next. The offset-4 member is a reserved library link; F:Amiga.ClipRect.Previous is retained as the legacy SDK compatibility name and must not be assumed to point to the prior Next node.
