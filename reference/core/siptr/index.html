SIPTR

Amiga.SIPTR

public readonly struct SIPTR

Signed pointer-sized integer used by MorphOS-style APIs.

CopperSharp currently lowers native integers to 32-bit values for its 68k target. Keep SIPTR out of fixed-width 68k guest records; use int or another explicitly sized type there.
