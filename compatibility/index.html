04 / OUTSIDE THE CURRENT CONTRACT

Deferred capabilities

Reachable use is diagnosed. These capabilities are not replaced with silent stubs.

AreaStatusCurrent surfaceEvidence
ReflectionDEFERREDGeneral reflection, metadata-driven activation, dynamic assembly loading and runtime code generation. Limited compiler-known type identity and name rendering are separate admitted operations.Profile boundary ↗
ConcurrencyDEFERREDThreads, tasks and general synchronization beyond explicitly declared contracts. Current culture storage represents one execution context; async/thread culture isolation is not implemented.Admission rules ↗
NetworkingDEFERREDGeneral .NET System.Net sockets, HTTP and network streams. Native typed SDK socket-library declarations are a separate API surface.Profile boundary ↗
Runtime servicesDEFERREDGeneral weak-reference/dependent-handle services, dynamic loading, COM and desktop frameworks. Individual admitted runtime helpers do not supply these services.Profile boundary ↗
GlobalizationDEFERREDNamed-culture locale data, complete Unicode globalization and concurrent culture flow. Audited numeric formatting can use NumberFormatInfo and application providers within its specific admission rules.Admission rules ↗
Array and interop formsDEFERREDMultidimensional arrays, arbitrary P/Invoke and general marshaling. Typed SDK/import declarations use explicit compiler and platform ABI contracts.Profile boundary ↗
